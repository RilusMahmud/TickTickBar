Design mockup & plan

TickTick Menu Bar

A native macOS menu-bar app that reads and writes through the local ticktick CLI — no embedded browser, no separate API layer. Catppuccin Mocha by default, Latte as a light variant.

1 · The popover

Two tabs in one 356 px popover, anchored under the menubar icon. Click around — the segmented control, checkboxes, and habit rings are live. Sample data includes your real overdue task.

2 · Palette

Catppuccin verbatim — no custom colors. Blue is the single interactive accent; green means done/checked; red means overdue/delete; mauve is brand only. Priority dots reuse red/yellow/blue.

3 · Build plan

SwiftUI MenuBarExtra (macOS 13+). The app is a thin, pretty shell; every read and write goes through the CLI as a child process, JSON in/out via JSONDecoder. No tokens in the app — auth stays in ticktick auth.

  • Why not Electron/Tauri: a checklist doesn't need a browser engine. Native menubar, ~5 MB, launches in one frame.
  • Refresh: poll filter every 5 min + on popover open + ⌘R; optimistic UI for complete/check-in, reconcile on response.
  • State: two structs — TaskRow, HabitRow — decoded straight from CLI JSON; a small TickTickCLIRunner wrapping Process.

  • Risk — search is down: the CLI's task search currently returns API 500; task filter works and is what the plan uses throughout.
